# -Line-Following-Car
Line-following robot for the Electronic Design Contest, featuring multi-sensor acquisition, weighted error calculation, PID control, and differential motor drive.
# 电赛循迹小车 | Line-Following Car

本系统设计了一辆具备自适应高速循线与车载滚球动态平衡功能的智能小车，整体架构由底盘运动控制、红外循迹、AI 视觉感知及无线图传四大子系统构成。

极速循迹：底盘采用 8 路红外灰度传感器阵列，结合归一化加权算法，在 1ms 极速主循环内运行位置式 PD 差速控制。配合带有霍尔编码器的 310 直流减速电机及底层增量式 PI 速度闭环，实现了极致流畅的高速过弯。

端侧 AI 平衡：搭载 K230 AI 视觉平台运行专属训练的钢珠目标检测大模型，配合触控屏交互式标定物理比例尺，精确获取钢球偏移量。通过 UART 实时与 MSPM0 主控通信，驱动摆杆伺服舵机进行闭环姿态修正，确保全场钢球零掉落。

无损图传：独立搭载 ESP32-S3-CAM 无线视频流子系统，为上位机提供高帧率监控画面。

强鲁棒硬件：采用“强弱电完全物理隔离”与全车共地设计，MP2482 动力降压结合 AMS1117 精密稳压，配合防脱轨记忆盲搜机制，确保在各种极限工况下系统“零复位”。

 硬件清单
 
主控制器：立创·天猛星开发板 (TI MSPM0G3507)

视觉模块：Canaan K230 (CanMV / Yahboom 架构)

图传模块：ESP32-S3-CAM (OV5640)

电机与驱动：双 520 / 310 霍尔编码器减速电机 + TB6612FNG

循迹模块：8 路红外光电开关阵列

电源系统：3S 11.1V 30C 高倍率动力锂电池 + MP2482 (DCDC 5V) + AMS1117 (LDO 3.3V)

交互外设：0.96 寸 I2C OLED 单色屏、独立按键


 软件架构特点
彻底的非阻塞设计：主循环（main.c）中剥离所有耗时操作，严格维持 1ms 的离散 PD 循迹运算周期。

多级并发中断：电机测速闭环与视觉串口解析全部下放至底层硬件 NVIC 中断异步执行，主循环零阻塞。

触控快门现场校准：K230 端创新性地引入“手指触控快门”功能，可在比赛现场 3 秒内快速重新标定 0cm 原点与比例尺，彻底杜绝机械微变导致的漂移。

快速上手
硬件连线：请严格参考我们报告中的系统总体框图，确保“大电流不进控制板”与共地。

主控烧录 (MSPM0)：使用 TI SysConfig 图形化工具或 Keil MDK 编译烧录 MSP_Control 目录下的代码。

视觉部署 (K230)：将 K230_Vision 目录下的 touch_calib_ai.py 烧录并设置上电自启。

性能指标实测
单圈循迹耗时：实测平均 17.02s，最高速度可突破 200 mm/s，停车定位偏差小于 0.4cm。

静态推球响应：从中心点至 ±5cm 处往返，误差控制在绝对 1cm 范围内。

动态行驶平衡：边跑边推球或维持指定点，钢珠全程无出轨。
